A program that writes the funniest single-line resignation letter it can: a subway announcer with six years on the platform quits using his own catchphrase — "stand clear of the closing doors" — turned back on the job itself. One line, 114 characters, deterministic output.

## Run it

```sh
node main.ts
```

This writes the resignation letter to `/output/entry.txt` (set `OUTPUT_PATH` to write elsewhere).
